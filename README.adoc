== Web y GitHub Pages

La web publicable está en `docs/index.html`. Incluye TRDR de 1.º ESO, PIAR I de 2.º ESO, PIAR II de 3.º ESO, Aplicaciones Ofimáticas de 1.º SMR y Administración de Sistemas Operativos de 2.º ASIR.

Para verla localmente, abra `docs/index.html` en el navegador. Todos los enlaces son relativos y funcionan también bajo la ruta `/PROGRAMACIONES2627/` de GitHub Pages.

Para publicarla después de subir los cambios al repositorio:

. Abra Settings → Pages en GitHub.
. En Build and deployment, seleccione Deploy from a branch.
. Seleccione la rama `main` y la carpeta `/docs`, y pulse Save.
. Espere al despliegue de GitHub Pages. La dirección prevista es https://mbanulsribes.github.io/PROGRAMACIONES2627/.

Esta reorganización no ha subido cambios ni activado Pages. Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site[Configurar el origen de publicación].

== Editar y actualizar la web

[cols="1,2",options="header"]
|===
|Programación |Fuente
|TRDR · 1.º ESO |`src/eso/trdr-1eso/index.adoc` y los capítulos de esa carpeta
|PIAR I · 2.º ESO |`src/eso/piar-i/programacion.adoc`
|PIAR II · 3.º ESO |`src/eso/piar-ii/programacion.adoc`
|AO · 1.º SMR |`src/atributos/ao.adoc`, `src/capitulos/ao/` y `src/modulos/ao.adoc`
|ASO · 2.º ASIR |`src/atributos/aso.adoc`, `src/capitulos/aso/`, `src/anexos/aso/` y `src/modulos/aso.adoc`
|===

Después de editar las fuentes:

[source,powershell]
----
./build-site.ps1
----

Este comando compila las cinco programaciones, crea el índice y copia únicamente las imágenes, estilos y PDF disponibles. Detiene la generación si Asciidoctor detecta advertencias. Suba las fuentes modificadas y la carpeta `docs` regenerada; GitHub Pages publica esa carpeta, no compila los AsciiDoc automáticamente. No edite los HTML generados a mano.

El catálogo está en `site/catalogo.json`. Para incorporar otra programación, añada una entrada con identificador único, título, nivel, etapa y ruta de su documento maestro. Los estilos de pantalla están en `site/site.css` y `site/document.css`.

== PDF y plantilla de Formación Profesional

[source,powershell]
----
./build.ps1                         # HTML y PDF de los módulos de FP
./build-pdf.ps1 -Modulo ao
./build-pdf.ps1 -Modulo aso
./new-module.ps1 -Id nuevo
./build-site.ps1                    # Actualiza la web después de compilar
----

Los scripts `build.ps1` y `build-pdf.ps1` trabajan con los módulos de FP de `src/modulos/`. Las tres materias de ESO se compilan a HTML mediante `build-site.ps1`. El sitio ofrece descargas de los PDF de AO y ASO cuando existen en `output/pdf/`, con la fecha de generación indicada. Si cambia una programación de FP, regenere su PDF antes de la web para mantener ambas versiones sincronizadas. No se han generado PDF nuevos para ESO.

La plantilla vacía está en `templates/modulo/`; la portada compartida, en `templates/portada.adoc`; el tema PDF, en `theme/font-programacion-theme.yml`. `scripts/pdf-cover.rb` aplica el panel gris de portada. Las fuentes de Windows están en `assets/fonts/` y no se publican en la web.

== Estructura

[source,text]
----
src/          Fuentes AsciiDoc de ESO y FP
site/         Catálogo y estilos de la web
scripts/      Generadores y extensión de portada PDF
templates/    Plantilla reutilizable de FP
assets/       Imágenes y fuentes locales
theme/        Estilo institucional y tema PDF
docs/         Web lista para GitHub Pages; incluir en Git
output/       Compilaciones e intermedios locales; excluido de Git
archivo/      Originales conservados y manifiestos de integridad
referencias/  DOCX original de referencia
.tools/       Compilador local; excluido de Git
----

`docs/.nojekyll` permite servir la web estática sin transformación de Jekyll. `docs/.generated-files.json` registra los archivos administrados por el generador; no lo edite. No se copian a la web el DOCX, los originales históricos, las fuentes de Windows ni el compilador.

== Requisitos y conservación

En este equipo `build-site.ps1` puede usar el compilador local JRuby con Java. Alternativamente, instale Ruby y Asciidoctor (`gem install asciidoctor`). Para PDF se necesita también `asciidoctor-pdf`. Versiones comprobadas: Asciidoctor 2.0.26 y Asciidoctor PDF 2.3.27.

Los originales iniciales permanecen en `archivo/originales/`, verificados mediante SHA-256. Las fuentes de ESO se han reubicado sin cambiar sus bytes; el manifiesto `archivo/manifiesto-migracion-pages.json` registra sus rutas previas y hashes. Consulte `MIGRACION.adoc` para las decisiones de la reorganización inicial. Los avisos de revisión y los acuerdos pendientes se conservan en las programaciones.
